External host page / Shadow DOM test

The widget should feel native without touching this page.

This is a plain HTML page with its own typography and component styles. The comment widget below is loaded through the public SDK and rendered inside a shadow root.

The purpose of this fixture is to expose accidental style leakage in both directions. The publication uses serif type and warm surfaces, while the widget carries its own pure-CSS visual language.

Inspect #bizme-comments-root in DevTools to confirm the composer and comment feed are mounted inside its shadow root rather than an iframe.
